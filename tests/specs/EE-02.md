# Test Spec: EE-02 — Pure transition function

**Requirement:** EE-02 — The execution engine SHALL implement a pure function: `(DefinitionSnapshot, InstanceState, Event) → NewInstanceState`. This function MUST have no I/O and be independently unit-testable.  
**Priority:** MUST  
**Test layer:** unit

## Test Cases

| Test Case ID | Acceptance Criterion | Description |
|--------------|---------------------|-------------|
| TC-EE-02-01 | Token placed on first non-START node after instance_started | Given an instance_started event, the token is placed on the first non-START node. |
| TC-EE-02-02 | HUMAN_TASK task_completed advances to next node | Given a task_completed event on a HUMAN_TASK, the token advances to the next node. |
| TC-EE-02-03 | Token reaches END node, status becomes COMPLETED | When a token reaches an END node, the instance status becomes COMPLETED. |
| TC-EE-02-04 | EXCLUSIVE_GATEWAY follows first true CEL condition | When a token enters an EXCLUSIVE_GATEWAY, the first true CEL condition is followed. |
| TC-EE-02-05 | No true EXCLUSIVE_GATEWAY condition, no default → error | If no condition is true and no default edge exists, the function returns NoMatchingEdge error. |
| TC-EE-02-06 | EXCLUSIVE_GATEWAY default edge fallback | If no condition is true but a default edge exists, the default edge is followed. |
| TC-EE-02-07 | PARALLEL_GATEWAY split creates N tokens | When a token enters a PARALLEL_GATEWAY split, N tokens are created for N outgoing edges. |
| TC-EE-02-08 | PARALLEL_GATEWAY join waits for all tokens | Join waits for all active tokens to arrive before merging. |
| TC-EE-02-09 | Unknown event type returns UnknownEventType error | An unknown event type returns UnknownEventType error. |
| TC-EE-02-10 | Token on missing node returns TokenOnMissingNode error | If a token is on a non-existent node, TokenOnMissingNode error is returned. |
| TC-EE-02-11 | Determinism: same inputs → identical output | Calling the function with the same inputs twice yields identical output. |

---

### TC-EE-02-01: instance_started event places token on first non-START node
**Given:** A DefinitionSnapshot with a START node and a HUMAN_TASK node, and an instance_started event.  
**When:** The transition function is called.  
**Then:** The token is placed on the HUMAN_TASK node.  
**Layer:** unit  
**Acceptance criterion mapped:** Token placement after instance start

### TC-EE-02-02: task_completed on HUMAN_TASK advances to next node
**Given:** A token on a HUMAN_TASK node with a valid outgoing edge to another node, and a task_completed event.  
**When:** The transition function is called.  
**Then:** The token advances to the next node.  
**Layer:** unit  
**Acceptance criterion mapped:** HUMAN_TASK completion advances token

### TC-EE-02-03: token reaches END → status becomes COMPLETED
**Given:** A token on a node with an outgoing edge to an END node, and a task_completed event.  
**When:** The transition function is called.  
**Then:** The token moves to the END node and status becomes COMPLETED.  
**Layer:** unit  
**Acceptance criterion mapped:** Completion on END node

### TC-EE-02-04: EXCLUSIVE_GATEWAY follows first true CEL condition
**Given:** A token on an EXCLUSIVE_GATEWAY node with multiple outgoing edges, each with a CEL condition, and a task_completed event.  
**When:** The transition function is called.  
**Then:** The token follows the first edge whose condition evaluates to true.  
**Layer:** unit  
**Acceptance criterion mapped:** Gateway condition evaluation

### TC-EE-02-05: EXCLUSIVE_GATEWAY with no true condition and no default → NoMatchingEdge error
**Given:** A token on an EXCLUSIVE_GATEWAY node with outgoing edges, none of whose conditions evaluate to true, and no default edge.  
**When:** The transition function is called.  
**Then:** The function returns NoMatchingEdge error.  
**Layer:** unit  
**Acceptance criterion mapped:** Gateway error path

### TC-EE-02-06: EXCLUSIVE_GATEWAY default edge fallback
**Given:** A token on an EXCLUSIVE_GATEWAY node with outgoing edges, none of whose conditions evaluate to true, but a default edge exists.  
**When:** The transition function is called.  
**Then:** The token follows the default edge.  
**Layer:** unit  
**Acceptance criterion mapped:** Gateway default edge

### TC-EE-02-07: PARALLEL_GATEWAY split creates N tokens
**Given:** A token on a PARALLEL_GATEWAY node with N outgoing edges.  
**When:** The transition function is called.  
**Then:** N tokens are created, one for each outgoing edge.  
**Layer:** unit  
**Acceptance criterion mapped:** Parallel split

### TC-EE-02-08: PARALLEL_GATEWAY join waits until all tokens arrive, then merges
**Given:** Multiple tokens approaching a PARALLEL_GATEWAY join node.  
**When:** All tokens have arrived.  
**Then:** The join fires and a single outgoing token is created.  
**Layer:** unit  
**Acceptance criterion mapped:** Parallel join

### TC-EE-02-09: unknown event type → UnknownEventType error
**Given:** An event of unknown type.  
**When:** The transition function is called.  
**Then:** The function returns UnknownEventType error.  
**Layer:** unit  
**Acceptance criterion mapped:** Unknown event error

### TC-EE-02-10: token on missing node → TokenOnMissingNode error
**Given:** A token referencing a node ID not present in the definition graph.  
**When:** The transition function is called.  
**Then:** The function returns TokenOnMissingNode error.  
**Layer:** unit  
**Acceptance criterion mapped:** Node existence validation

### TC-EE-02-11: same inputs called twice → identical output (determinism)
**Given:** A fixed DefinitionSnapshot, InstanceState, and Event.  
**When:** The transition function is called twice with the same inputs.  
**Then:** Both calls return identical output.  
**Layer:** unit  
**Acceptance criterion mapped:** Determinism
