# EE-01 — Start Instance: Test Specification

**Requirement:** EE-01 — Start Process Instance  
**Implementation:** `src/engine/instance.zig` (InstanceStore.create), `src/api/routes/instances.zig` (handleCreate)  
**Test file:** `tests/integration/ee01_start_instance_test.zig`

---

## Acceptance Criteria (from EE-01)

- AC-1: POST /api/v1/instances with a valid ACTIVE definition_id and JSON object initial_variables → 201 with instance_id, status=ACTIVE
- AC-2: Providing correlation_key stores it and enforces per-definition uniqueness
- AC-3: Non-existent definition_id → 404 DEFINITION_NOT_FOUND
- AC-4: DRAFT or DEPRECATED definition → 409 DEFINITION_NOT_ACTIVE
- AC-5: Duplicate correlation_key for the same definition_id → 409 DUPLICATE_CORRELATION_KEY
- AC-6: initial_variables must be a JSON object; null or array → 422 INVALID_INITIAL_VARIABLES
- AC-7: Definition snapshot captured in instance_definition_snapshots at start time

---
