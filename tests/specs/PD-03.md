# Test Spec: PD-03 — Version management

**Requirement:** PD-03 — Version management (MUST) — Each definition name MAY have multiple
versions. Only one version per name SHALL be in ACTIVE status at a time. Activating a version
automatically sets the prior active version to DEPRECATED.

**Priority:** MUST  
**Test layer:** integration (Store.activate() requires a real PostgreSQL database)

---

## Shared preconditions

- A real PostgreSQL database is reachable at `BPM_TEST_DB_URL`.
- All migrations have been applied (via `TestHarness.init()`).
- A `definition.Store` is created with a live `Pool`.
- A fixed `created_by` UUID `00000000-0000-0000-0000-000000000099` is used in all tests.
- Each test that writes to the database removes its rows on exit via `cleanupByName()`.
- A minimal valid graph (START → USER_TASK → END) is reused across tests.

---

## Test Cases

### TC-PD-03-01: Prior ACTIVE version is atomically deprecated on new activation

**Given:** definition name N has version V1 in status ACTIVE (activated earlier).  
**When:** version V2 of the same name N is activated via `Store.activate(v2.id)`.  
**Then:**
- `activate()` returns success with status `ACTIVE` for V2.
- `Store.getById(v1.id)` returns V1 with status `DEPRECATED`.
- Both status changes occur in the same transaction (no transient state where both are ACTIVE).

**Layer:** integration  
**Acceptance criterion mapped:** PD-03 — "GIVEN definition name N has an existing ACTIVE version
V1, WHEN version V2 is activated for name N, THEN V1's status changes to DEPRECATED atomically in
the same transaction."

---

### TC-PD-03-02: At no point may two versions of the same name simultaneously be ACTIVE

**Given:** name N has V1 in status ACTIVE.  
**When:** V2 is activated for name N.  
**Then:** `Store.list(name=N, status=ACTIVE)` returns exactly one result.

**Layer:** integration  
**Acceptance criterion mapped:** PD-03 — "At no point MAY two versions of the same name
simultaneously have `status = ACTIVE`."

---

### TC-PD-03-03: First activation of a name succeeds with no prior deprecation side-effect

**Given:** definition name N has exactly one DRAFT version V1 and no prior ACTIVE version.  
**When:** `Store.activate(v1.id)` is called.  
**Then:**
- Returns V1 with status `ACTIVE`.
- `Store.list(name=N)` returns exactly one definition with status `ACTIVE`.
- No other row is updated (no spurious DEPRECATED rows for unrelated names).

**Layer:** integration  
**Acceptance criterion mapped:** PD-03 — "GIVEN a definition name with no ACTIVE version, WHEN the
first version is activated, THEN it becomes ACTIVE with no prior version to deprecate."

---

### TC-PD-03-04: Listing by status=ACTIVE returns at most one version per name

**Given:** name N has had V1 activated (now DEPRECATED) and V2 activated (now ACTIVE).  
**When:** `Store.list(name=N, status=ACTIVE)` is called.  
**Then:** the returned slice contains exactly one entry and its status is `ACTIVE`.

**Layer:** integration  
**Acceptance criterion mapped:** PD-03 — "Listing definitions filtered by `status=ACTIVE` MUST
return at most one version per name."

---

### TC-PD-03-05: Activating the already-ACTIVE version is a no-op that returns success

**Given:** version V1 of name N is already in status ACTIVE.  
**When:** `Store.activate(v1.id)` is called again.  
**Then:**
- Returns success (no error); the returned Definition has status `ACTIVE`.
- `Store.list(name=N, status=ACTIVE)` still returns exactly one result.

**Layer:** integration  
**Acceptance criterion mapped:** PD-03 edge case — "Activating the already-ACTIVE version of the
same name: no-op; returns HTTP 200 (idempotent)."

---

### TC-PD-03-06: Activating a DEPRECATED or ARCHIVED version is rejected with NotDraft

**Given (DEPRECATED case):** V1 was activated and subsequently deprecated by V2's activation.  
**When:** `Store.activate(v1.id)` is called on the now-DEPRECATED V1.  
**Then:** returns `DefinitionError.NotDraft`.

**Given (ARCHIVED case):** A DRAFT definition D has been updated to status `ARCHIVED` directly.  
**When:** `Store.activate(D.id)` is called.  
**Then:** returns `DefinitionError.NotDraft`.

**Layer:** integration  
**Acceptance criterion mapped:** PD-03 edge case — "Activating a DEPRECATED or ARCHIVED version:
rejected with HTTP 409 (only DRAFT definitions can be activated)."
