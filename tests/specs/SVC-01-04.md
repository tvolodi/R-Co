## SVC-01 — Service catalog scope and owner tenant

### TC-SVC-01-01: Global service is visible to any tenant (DB SQL filter)
**Layer:** Integration (DB)  
**Source:** `svc01_service_catalog_scope_test.zig`  
**Test name:** `svc01: global service visible to any tenant`  
**Criterion:** `scope = 'global'` entries are returned for any caller_tenant_id.  
**Fail if:** Query `WHERE scope='global' OR owner_tenant_id=$1` does not include the global service.

### TC-SVC-01-02: Tenant-scoped service visible only to owner tenant (DB SQL filter)
**Layer:** Integration (DB)  
**Source:** `svc01_service_catalog_scope_test.zig`  
**Test name:** `svc01: tenant-scoped service visible only to owner tenant`  
**Criterion:** `scope = 'tenant'` entry appears for its owner tenant, does not appear for a different tenant.  
**Fail if:** Query returns 0 rows for owner tenant, or returns 1 row for a different tenant.

### TC-SVC-01-03: CHECK constraint rejects scope=tenant with NULL owner_tenant_id
**Layer:** Integration (DB)  
**Source:** `svc01_service_catalog_scope_test.zig`  
**Test name:** `svc01: check constraint rejects scope=tenant with NULL owner`  
**Criterion:** INSERT with `scope='tenant', owner_tenant_id=NULL` raises `error.PgError`.  
**Fail if:** INSERT succeeds.

### TC-SVC-01-04: ON DELETE CASCADE removes scoped service when owner tenant is deleted
**Layer:** Integration (DB)  
**Source:** `svc01_service_catalog_scope_test.zig`  
**Test name:** `svc01: on_delete_cascade removes scoped service when owner tenant deleted`  
**Criterion:** After `DELETE FROM tenant WHERE id=$1`, the scoped service row is removed.  
**Fail if:** Service row still present after tenant deletion.

### TC-SVC-01-05: Existing rows have scope defaulting to 'global' (no NULL scope)
**Layer:** Integration (DB)  
**Source:** `svc01_service_catalog_scope_test.zig`  
**Test name:** `svc01: existing rows default to scope=global`  
**Criterion:** `SELECT COUNT(*) FROM service_catalog WHERE scope IS NULL` returns 0.  
**Fail if:** Any row has NULL scope after migration GBL-078.

### TC-SVC-01-06: listServicesForTenant filters by tenant via ServiceCatalog store API
**Layer:** Integration (DB + store API)  
**Source:** `svc01_service_catalog_scope_test.zig`  
**Test name:** `svc01: listServicesForTenant filters correctly via store API`  
**Criterion:** `ServiceCatalog.listServicesForTenant` with a tenant_id returns global entries and
own tenant-scoped entries but not another tenant's scoped entries.  
**Fail if:** Another tenant's scoped service appears in results.

### TC-SVC-01-07: getServiceForTenant returns ServiceNotFound for cross-tenant scoped service
**Layer:** Integration (DB + store API)  
**Source:** `svc01_service_catalog_scope_test.zig`  
**Test name:** `svc01: getServiceForTenant returns ServiceNotFound for cross-tenant service`  
**Criterion:** `ServiceCatalog.getServiceForTenant` returns `error.ServiceNotFound` when the service
belongs to a different tenant.  
**Fail if:** Function returns a record instead of `error.ServiceNotFound`.

### TC-SVC-01-08: registerService correctly stores scope and owner_tenant_id
**Layer:** Integration (DB + store API)  
**Source:** `svc01_service_catalog_scope_test.zig`  
**Test name:** `svc01: registerService stores scope and owner_tenant_id correctly`  
**Criterion:** After `registerService` with `scope=.tenant`, the returned record has the correct
scope and owner_tenant_id; subsequent `getService` confirms persistence.  
**Fail if:** Returned or persisted scope/owner_tenant_id does not match params.

### TC-SVC-01-09: registerService with scope=global+owner_tenant_id returns InvalidScopeConstraint
**Layer:** Integration (store API)  
**Source:** `svc01_service_catalog_scope_test.zig`  
**Test name:** `svc01: registerService rejects scope=global with owner_tenant_id`  
**Criterion:** `registerService` with `scope=.global, owner_tenant_id=<some_uuid>` returns
`error.InvalidScopeConstraint`.  
**Fail if:** Registration succeeds or returns a different error.

### TC-SVC-01-10: platform-admin listServicesForTenant (nil caller) returns all entries
**Layer:** Integration (DB + store API)  
**Source:** `svc01_service_catalog_scope_test.zig`  
**Test name:** `svc01: listServicesForTenant with nil tenant returns all entries`  
**Criterion:** `listServicesForTenant(allocator, null, ...)` returns both global and all tenant-scoped
entries regardless of owner.  
**Fail if:** Tenant-scoped entries are absent when caller_tenant_id is null.

## SVC-02 — Plugin registry tenant scoping

### TC-SVC-02-01: registerPluginHandler rejects scope=tenant with null owner_tenant_id
**Layer:** Unit (in-process)  
**Source:** `svc02_plugin_dispatch_scope_test.zig`  
**Test name:** `svc02: registerPluginHandler rejects tenant scope without owner_tenant_id`  
**Criterion:** `registerPluginHandler` with `scope=.tenant, owner_tenant_id=null` returns
`error.TenantScopedPluginRequiresOwnerId`.  
**Fail if:** Registration succeeds or returns a different error.

### TC-SVC-02-02: registerPluginHandler rejects scope=global with non-null owner_tenant_id
**Layer:** Unit (in-process)  
**Source:** `svc02_plugin_dispatch_scope_test.zig`  
**Test name:** `svc02: registerPluginHandler rejects global scope with owner_tenant_id`  
**Criterion:** `registerPluginHandler` with `scope=.global, owner_tenant_id=<some_uuid>` returns
`error.GlobalPluginMustNotHaveOwnerId`.  
**Fail if:** Registration succeeds or returns a different error.

### TC-SVC-02-03: resolvePluginHandlerForTenant returns tenant-scoped plugin for owner tenant
**Layer:** Unit (in-process)  
**Source:** `svc02_plugin_dispatch_scope_test.zig`  
**Test name:** `svc02: resolvePluginHandlerForTenant returns tenant plugin for owner`  
**Criterion:** When a tenant-scoped plugin is registered for tenant T and a global plugin for the
same node_type also exists, `resolvePluginHandlerForTenant(T)` returns the tenant-scoped one.  
**Fail if:** Global plugin is returned instead of tenant-scoped one.

### TC-SVC-02-04: resolvePluginHandlerForTenant falls back to global for non-owner tenant
**Layer:** Unit (in-process)  
**Source:** `svc02_plugin_dispatch_scope_test.zig`  
**Test name:** `svc02: resolvePluginHandlerForTenant falls back to global for non-owner`  
**Criterion:** `resolvePluginHandlerForTenant(U)` where U ≠ T returns the global plugin.  
**Fail if:** Tenant-scoped plugin (owned by T) is returned for tenant U.

### TC-SVC-02-05: resolvePluginHandlerForTenant returns nil when no global and non-owner tenant
**Layer:** Unit (in-process)  
**Source:** `svc02_plugin_dispatch_scope_test.zig`  
**Test name:** `svc02: resolvePluginHandlerForTenant returns nil for unregistered tenant`  
**Criterion:** With only a tenant-scoped plugin (owner=T) registered, `resolvePluginHandlerForTenant(U)`
returns null.  
**Fail if:** A non-null PluginRegistration is returned.

### TC-SVC-02-06: freezePluginRegistry detects duplicate (node_type, owner_tenant_id) combinations
**Layer:** Unit (in-process — via detection before freeze)  
**Source:** `svc02_plugin_dispatch_scope_test.zig`  
**Test name:** `svc02: two tenant-scoped plugins for same (node_type, owner_tenant_id) detected`  
**Criterion:** After registering two tenant-scoped plugins with identical `(node_type, owner_tenant_id)`,
calling `freezePluginRegistry` triggers a fatal panic (verified via test expectation of panic behavior).
The check exists and can be observed by inspecting the registry state before freeze.  
**Fail if:** Duplicate entries are silently ignored.

## SVC-03 — Definition activation scope validation

### TC-SVC-03-01: Activation passes for definition with global service reference
**Layer:** Integration (validator + DB)  
**Source:** `svc03_definition_activation_scope_test.zig`  
**Test name:** `svc03: activation passes for global service reference`  
**Criterion:** `ServiceScopeValidator.validateServiceTaskReferences` returns `void` when the
referenced service has `scope='global'`.  
**Fail if:** Function returns an error.

### TC-SVC-03-02: Activation passes for definition with own-tenant scoped service reference
**Layer:** Integration (validator + DB)  
**Source:** `svc03_definition_activation_scope_test.zig`  
**Test name:** `svc03: activation passes for own-tenant scoped service`  
**Criterion:** Validator returns `void` when the SERVICE_TASK references a tenant-scoped service
whose `owner_tenant_id` equals the activating tenant.  
**Fail if:** Function returns `error.ServiceNotAvailableToTenant`.

### TC-SVC-03-03: Activation rejected for cross-tenant scoped service reference
**Layer:** Integration (validator + DB)  
**Source:** `svc03_definition_activation_scope_test.zig`  
**Test name:** `svc03: activation rejected for cross-tenant service reference`  
**Criterion:** Validator returns `error.ServiceNotAvailableToTenant` when the SERVICE_TASK references
a tenant-scoped service owned by a different tenant.  
**Fail if:** Validation passes or returns a different error.

### TC-SVC-03-04: Activation rejected for unregistered service reference
**Layer:** Integration (validator + DB)  
**Source:** `svc03_definition_activation_scope_test.zig`  
**Test name:** `svc03: activation rejected for unregistered service reference`  
**Criterion:** Validator returns `error.ServiceNotRegistered` when the `service_id` has no catalog
entry.  
**Fail if:** Validation passes or returns a different error.

### TC-SVC-03-05: Activation rejected for cross-tenant plugin_handler reference
**Layer:** Unit (validator + in-process plugin registry)  
**Source:** `svc03_definition_activation_scope_test.zig`  
**Test name:** `svc03: activation rejected for cross-tenant plugin_handler`  
**Criterion:** Validator returns `error.PluginNotAvailableToTenant` when a SERVICE_TASK specifies
a `plugin_handler` that is a tenant-scoped plugin registered for a different tenant.  
**Fail if:** Validation passes or returns a different error.

### TC-SVC-03-06: Activation passes for own-tenant plugin_handler reference
**Layer:** Unit (validator + in-process plugin registry)  
**Source:** `svc03_definition_activation_scope_test.zig`  
**Test name:** `svc03: activation passes for own-tenant plugin_handler`  
**Criterion:** Validator returns `void` when the `plugin_handler` refers to a tenant-scoped plugin
owned by the activating tenant.  
**Fail if:** Function returns an error.

### TC-SVC-03-07: Activation is atomic — first violation stops validation
**Layer:** Unit (validator + DB)  
**Source:** `svc03_definition_activation_scope_test.zig`  
**Test name:** `svc03: first scope violation stops validation atomically`  
**Criterion:** A definition with two SERVICE_TASK nodes where the first is a cross-tenant service
and the second is a global service: the validator returns `error.ServiceNotAvailableToTenant` (not
`void`), confirming fail-fast behavior.  
**Fail if:** Validation passes or `lastViolation()` is null after failure.

## SVC-04 — Admin API route handlers

status 201.

**Source:** `svc04_admin_api_test.zig`  
**Test name:** `svc04: admin register duplicate service_id returns 409`
