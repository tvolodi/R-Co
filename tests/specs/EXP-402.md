# Test Spec: EXP-402 - Restore Reconciliation from instance_waits

**Requirement:** EXP-402
**Priority:** MUST
**Test layer:** integration (real PostgreSQL)

## Scope

This spec verifies restore-time reconciliation behavior using durable `instance_waits` descriptors:
- Re-arm count computed from unresolved wait descriptors with live backing rows
- `restored_orphan` marking when unresolved descriptors cannot be safely re-armed
- Operator-visible orphan reason persisted on the instance projection

## Test Cases

### TC-EXP-402-01: Reconciliation re-arms live timer and task waits
**Given:** An instance with unresolved timer and human-task descriptors, and both backing rows still live (`timers.status='pending'`, `tasks.status='PENDING'`).
**When:** `restoreTenantWithWaitReconciliation()` runs for the tenant.
**Then:** Result reports one restored instance, two re-armed waits, zero orphaned instances; instance status remains non-orphan.
**Layer:** integration
**Acceptance criterion mapped:** restore reconciliation using EXP-103 descriptors.

### TC-EXP-402-02: Unrearmable descriptor marks instance RESTORED_ORPHAN
**Given:** An instance with unresolved `instance_waits` descriptor but no corresponding live wait row.
**When:** `restoreTenantWithWaitReconciliation()` runs for the tenant.
**Then:** Result reports one orphaned instance; `instance_projections.status='RESTORED_ORPHAN'`; `error_detail.restored_orphan_reason` is populated.
**Layer:** integration
**Acceptance criterion mapped:** restored_orphan marking/surface behavior.
