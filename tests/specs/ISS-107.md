# Test Spec: ISS-107 — Add `public.tenant.storage_mode` flag

**Requirement:** ISS-107 — Add `public.tenant.storage_mode TEXT NOT NULL DEFAULT 'LEGACY_RLS' CHECK (storage_mode IN ('LEGACY_RLS','SCHEMA'))` so each tenant has exactly one authoritative storage path during SPT coexistence.

**Priority:** MUST
**Test layer:** integration

## Acceptance Criteria

| ID | Criterion | Covered by |
|---|---|---|
| AC-1 | GBL- migration adds `public.tenant.storage_mode TEXT NOT NULL DEFAULT 'LEGACY_RLS' CHECK (...)` | TC-ISS-107-01 |
| AC-2 | Existing tenants default to `LEGACY_RLS`; newly provisioned tenants default to `SCHEMA` | TC-ISS-107-02, TC-ISS-107-05 |

## Test Cases

### TC-ISS-107-01: tenant table has storage_mode column with correct type and default
**Given:** The migration 086 has been applied
**When:** `information_schema.columns` is queried for the `tenant` table
**Then:** A `storage_mode` column exists with `TEXT` type, `is_nullable=NO`, and `column_default='LEGACY_RLS'::text`
**Layer:** integration
**Acceptance criterion mapped:** AC-1 (column shape)

### TC-ISS-107-02: inserting a tenant without specifying storage_mode gets DEFAULT
**Given:** A new tenant row is inserted without specifying `storage_mode`
**When:** The row is SELECTed back
**Then:** `storage_mode` equals `'LEGACY_RLS'`
**Layer:** integration
**Acceptance criterion mapped:** AC-2 (existing tenant path default)

### TC-ISS-107-03: inserting storage_mode='SCHEMA' succeeds
**Given:** A new tenant row with `storage_mode='SCHEMA'`
**When:** The row is SELECTed back
**Then:** `storage_mode` equals `'SCHEMA'`
**Layer:** integration
**Acceptance criterion mapped:** AC-2 (new tenant path)

### TC-ISS-107-04: invalid storage_mode value is rejected by CHECK constraint
**Given:** An UPDATE on tenant set `storage_mode='BOGUS'`
**When:** The UPDATE is executed
**Then:** A CHECK constraint violation (PG error 23514) is raised and the row retains its original value
**Layer:** integration
**Acceptance criterion mapped:** AC-1 (CHECK domain)

### TC-ISS-107-05: provisionTenantSchema sets storage_mode to SCHEMA
**Given:** A new tenant is provisioned via `provisionTenantSchema()`
**When:** The tenant row is SELECTed back
**Then:** `storage_mode` equals `'SCHEMA'`
**Layer:** integration
**Acceptance criterion mapped:** AC-2 (newly provisioned tenant path)
