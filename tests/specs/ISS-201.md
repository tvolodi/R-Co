# Test Spec: ISS-201 -- transition() returns TransitionResult{state, emitted_events}

**Requirement:** ISS-201 -- Make `transition()` return `{state, emitted_events}` instead of returning `InstanceState` with an embedded `pending_events` field.
**Priority:** MUST
**Test layer:** unit, integration

## Acceptance Criteria Mapped

| AC | Description | Test Cases |
|---|---|---|
| AC-1 | transition() returns TransitionResult{state, emitted_events} | TC-ISS-201-01 through TC-ISS-201-07 |
| AC-2 | InstanceState has no pending_events field (compile-time) | TC-ISS-201-07 |
| AC-3 | Trigger + emitted_events committed atomically | TC-ISS-201-IT-01 |

## Test Cases

### TC-ISS-201-01: TIMER entry emits timer_created event
**Given:** Definition graph START -> TIMER("PT0S")
**When:** instance_started fires
**Then:** TransitionResult.emitted_events contains exactly 1 event of variant .timer_created with timer_node_id="timer1" and duration_iso8601="PT0S"
**Layer:** unit (transition.zig embedded test TC-SCH-01-01, line 1064)
**Acceptance criterion mapped:** AC-1 -- TransitionResult.emitted_events carries the timer_created side-effect

### TC-ISS-201-02: Sub-process entry emits sub_process_start event
**Given:** Definition graph START -> SUB_PROCESS(child_definition_id="...")
**When:** instance_started fires
**Then:** TransitionResult.emitted_events contains exactly 1 event of variant .sub_process_start
**Layer:** unit (transition.zig embedded test TC-EXT-05-UT-01, line 1740)
**Acceptance criterion mapped:** AC-1 -- TransitionResult.emitted_events carries the sub_process_start side-effect

### TC-ISS-201-03: Parallel split emits parallel_split event with edge_count
**Given:** Definition graph START -> PARALLEL_GATEWAY(par) -> {END_A, END_B}
**When:** instance_started fires, traversing the parallel gateway with 2 outgoing edges
**Then:** TransitionResult.emitted_events contains exactly 1 event of variant .parallel_split with edge_count=2, source_node_id="par"
**Layer:** unit (test_engine_apply.zig TC-EE-03-05 + transition.zig embedded TC-EE-06-01/TC-EE-06-05)
**Acceptance criterion mapped:** AC-1 -- parallel_split event emitted with correct token_ids and edge_count

### TC-ISS-201-04: Parallel join emits parallel_join event with arrived/cancelled branches
**Given:** 3-branch parallel workflow, all 3 tasks complete sequentially
**When:** The third and final token arrives at the join gateway
**Then:** TransitionResult.emitted_events contains exactly 1 event of variant .parallel_join with join_node_id="join_gw", branch_ids_arrived.len=3, branch_ids_cancelled.len=0, outgoing_token_id=the deterministic merged branch_id
**Layer:** unit (test_ee07_parallel_join.zig TC-EE-07-05)
**Acceptance criterion mapped:** AC-1 -- parallel_join event emitted with correct arrived/cancelled branch tracking

### TC-ISS-201-05: Normal node entry (HUMAN_TASK, START, END, EXCLUSIVE_GATEWAY) produces empty emitted_events
**Given:**
  - (a) Definition START -> HUMAN_TASK("task1"); instance_started fires
  - (b) Definition START -> END; instance_started fires
  - (c) Definition with EXCLUSIVE_GATEWAY; gateway traversal routes to next node
  - (d) Definition with SERVICE_TASK; service_task_completed advances to END
**When:** transition() is called for each of the above
**Then:** TransitionResult.emitted_events.len == 0 in every case (no side-effect events from normal node entry)
**Layer:** unit (test_engine_apply.zig TC-EE-03-01/02/03/04, test_engine_ee05.zig TC-EE-05-01/02/03/05, service_task_test.zig TC-EXT-01-U09)
**Acceptance criterion mapped:** AC-1 -- nodes without side-effects produce empty emitted_events

### TC-ISS-201-06: Error path -- transition() returns error, emitted_events not populated
**Given:** Definition EXCLUSIVE_GATEWAY with two non-default false edges, no default edge
**When:** transition() is called
**Then:** TransitionError.NoMatchingEdge is returned (error union, not TransitionResult). emitted_events is moot -- the caller never receives a result struct.
**Layer:** unit (test_engine_ee05.zig TC-EE-05-04)
**Acceptance criterion mapped:** AC-1 -- error paths never produce a TransitionResult with partial emitted_events

### TC-ISS-201-07: InstanceState no longer has .pending_events field (compile-time check)
**Given:** The source code at src/engine/transition.zig
**When:** The code is compiled
**Then:** InstanceState struct has no `pending_events` field. Any attempt to reference `state.pending_events` is a compile error.
**Layer:** unit (compile-time verification -- already enforced by the ISS-201 implementation)
**Acceptance criterion mapped:** AC-2 -- pending_events removed from InstanceState

### TC-ISS-201-IT-01: Trigger event + emitted_events committed atomically in one transaction
**Given:** A definition with START -> TIMER("PT5M") -> END
**When:** An instance is created via InstanceStore.create()
**Then:**
  - Both the instance_started event row AND the timer row exist in the database
  - The timer payload contains the correct node_id ("WAIT_TIMER")
  - The timer instance_id matches the created instance
**Layer:** integration (tests/integration/iss201_transition_result_test.zig)
**Acceptance criterion mapped:** AC-3 -- atomic trigger+emitted commit in single PostgreSQL transaction
