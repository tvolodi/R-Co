# ISS-501 Test Specification: Storage Mode Routing

## Requirement
ISS-501: Resolve read/write authority from storage_mode

## Test Cases

### TC-ISS501-01: LEGACY_RLS tenant gets public search_path with RLS
- **Layer:** Integration
- **Precondition:** Tenant exists with storage_mode='LEGACY_RLS'
- **Steps:**
  1. Authenticate as a user in the LEGACY_RLS tenant
  2. Make a GET request to /api/v1/process-definitions
  3. Verify the query executes against the public schema
- **Expected:** Response returns data from public schema. `SHOW search_path` would show `public`. `current_setting('bpm.tenant_id')` is set.

### TC-ISS501-02: SCHEMA tenant gets tenant schema search_path
- **Layer:** Integration
- **Precondition:** Tenant exists with storage_mode='SCHEMA' and tenant schema created
- **Steps:**
  1. Authenticate as a user in the SCHEMA tenant
  2. Make a GET request to /api/v1/process-definitions
  3. Verify the query executes against the tenant schema
- **Expected:** Response returns data from tenant schema. `SHOW search_path` would show `tenant_{slug},public`. `current_setting('bpm.tenant_id')` is not set.

### TC-ISS501-03: Storage mode cached per request (no re-query)
- **Layer:** Unit (mock)
- **Precondition:** tenant_context initialized
- **Steps:**
  1. Set storage mode to SCHEMA via setStorageMode()
  2. Call getStorageMode() twice
  3. Call hasStorageMode()
- **Expected:** Both calls return SCHEMA. hasStorageMode() returns true.

### TC-ISS501-04: Clear resets storage mode
- **Layer:** Unit
- **Precondition:** storage mode set to SCHEMA
- **Steps:**
  1. Set storage mode to SCHEMA
  2. Call clear()
  3. Call getStorageMode() and hasStorageMode()
- **Expected:** getStorageMode() returns LEGACY_RLS. hasStorageMode() returns false.

### TC-ISS501-05: No-tenant request uses public schema only
- **Layer:** Integration
- **Precondition:** Bootstrap token used (no tenant context)
- **Steps:**
  1. Make a request with bootstrap token
  2. Verify no tenant_id is set in session
- **Expected:** search_path = public only. No set_config calls.
