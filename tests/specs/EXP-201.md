# Test Spec: EXP-201 - Entity Definition Format

Requirement: EXP-201 - Entity definition format + repository artifact integration
Priority: MUST
Test layer: integration

## Test Cases

### TC-EXP-201-01: create definition persists canonical content hash and metadata
Given: a real PostgreSQL test database and a valid entity definition JSON
When: createDefinition is called with name, display name, and definition_json
Then: a definition row is created with expected name, DRAFT status, and non-empty content_hash
Layer: integration
Acceptance criterion mapped: entity definition JSON is persisted with deterministic canonicalisation metadata

### TC-EXP-201-02: activate definition marks definition ACTIVE
Given: a definition created in DRAFT state
When: activateDefinition is called for that definition id
Then: the returned definition status is ACTIVE
Layer: integration
Acceptance criterion mapped: entity definition lifecycle activation is functional

### TC-EXP-201-03: queried json field is rejected by validator
Given: a definition JSON containing a field with queried=true and type=json
When: validateDefinition is executed
Then: validation fails with FieldQueriedAndJson
Layer: integration
Acceptance criterion mapped: queried/json exclusion rule is enforced
