# Test Spec: EXP-202 — Entity Command API

## Description
Verify the event-sourced command path for entity records. This includes creation, updates, and deletion through REST API routes, ensuring atomicity between event appends and projection updates.

## Covered Requirements
- EXP-202: Entity command API
  - EXP-202-1: Create record (POST)
  - EXP-202-2: Update record (PATCH)
  - EXP-202-3: Delete record (DELETE)
  - EXP-202-4: Atomic transaction (Event + Projection)
  - EXP-202-5: Idempotency (via `idempotency_key`)

## Test Cases

### TC-EXP-202-01: Create Entity Record
- **Description:** Successfully create a record for a defined entity type.
- **Precondition:** Entity definition "customer" exists.
- **Action:** `POST /api/v1/entities/customer` with `{"email": "test@example.com", "age": 25}` and unique `Idempotency-Key`.
- **Expected Outcome:** 
  - Status 201 Created. 
  - Response body contains `record_id` (UUID).
  - Event `ENTITY_RECORD_CREATED` exists in `events` table.
  - Record exists in `entity_record_latest` with `version_seq = 1`.

### TC-EXP-202-02: Update Entity Record
- **Description:** Update an existing record.
- **Precondition:** Customer record `R1` exists (`version_seq = 1`).
- **Action:** `PATCH /api/v1/entities/customer/R1` with `{"age": 26}`.
- **Expected Outcome:** 
  - Status 200 OK.
  - Event `ENTITY_RECORD_UPDATED` appended.
  - `entity_record_latest` updated with `age = 26` and `version_seq = 2`.

### TC-EXP-202-03: Delete Entity Record
- **Description:** Soft-delete an entity record.
- **Precondition:** Customer record `R1` exists.
- **Action:** `DELETE /api/v1/entities/customer/R1`.
- **Expected Outcome:** 
  - Status 204 No Content.
  - Event `ENTITY_RECORD_DELETED` appended.
  - `entity_record_latest` for `R1` has `is_deleted = true`.

### TC-EXP-202-04: Idempotent Creation
- **Description:** Verify that re-sending the same `Idempotency-Key` returns the original result without duplicate effects.
- **Action:** Send `POST /api/v1/entities/customer` twice with the same key.
- **Expected Outcome:** 
  - First call: 201 Created.
  - Second call: 201 Created (or 200). `is_duplicate` is true in internal result.
  - Only one event appended to `events` table.

### TC-EXP-202-05: Atomic Transaction Failure
- **Description:** Verify that if the projection update fails, the event is not persisted (or vice versa).
- **Setup:** Manual database constraint violation or mock failure in `updateProjection`.
- **Action:** Attempt to create an entity record.
- **Expected Outcome:** 
  - Status 500 Internal Error.
  - No event in `events` table.
  - No row in `entity_record_latest`.

### TC-EXP-202-06: Create with Invalid Payload
- **Description:** Reject record creation if payload values violate definition (e.g. required field missing).
- **Action:** `POST /api/v1/entities/customer` with empty JSON `{}`.
- **Expected Outcome:** Status 422 Unprocessable Entity.
