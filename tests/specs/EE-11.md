# Test Spec: EE-11 — State Reconstruction

**Requirement:** EE-11 — At any time, the platform SHALL be able to reconstruct the full
current state of any instance by replaying its event log from the beginning. Reconstructed
state MUST be identical to persisted state. Reconstruction MUST complete within the time
bound defined in NFR-04.

**Priority:** MUST

**Test layer:** unit (TC-EE-11-U01 through TC-EE-11-U03), integration (TC-EE-11-01 through
TC-EE-11-09)

---

## Acceptance Criteria (verbatim from spec)

1. GIVEN an instance with N events in its event log, WHEN state reconstruction is invoked,
   THEN the platform replays all N events through the pure transition function (EE-02) and
   produces an `InstanceState` equal to the persisted projection, field-for-field: same
   active tokens, same variable map, same task set, same instance status.
2. Reconstruction MUST complete within NFR-04 (≤ 5 seconds for up to 10,000 events).
3. Reconstruction MUST be possible even if the read-model (projection table) is corrupt or
   absent.
4. After successful reconstruction, the platform MAY write the result back to the projection
   table to restore the read model.
5. Reconstruction that spans both `events` and `events_archive` tables (ES-07) MUST produce
   identical results to pre-archival reconstruction.
6. Edge case: Instance with 0 events returns `InstanceNotFound` (instance was never started
   per design §5).
7. Edge case: Event log contains an `EXECUTION_ERROR` event: reconstructed status = ERROR.

---

## Test Cases

### TC-EE-11-01: Basic reconstruction — N events produce InstanceState equal to persisted projection

**Given:**
- A process definition with nodes: `start` → `review_task` → `end`.
- An ACTIVE process instance whose event log contains (in order):
  `instance_started` (start_node_id=`review_task`, initial_variables=`{}`),
  `task_completed` (task_node_id=`review_task`, output_variables=`{"result":"approved"}`).
- The `instance_projections` row for this instance reflects the state after both events:
  `status = ACTIVE`, `current_nodes = [{"node_id":"end","branch_id":"0"}]`,
  `variables = {"result":"approved"}`.

**When:**
- `reconstructInstance(allocator, pool, snapshot_store, instance_id, false)` is called
  (write_back = false).

**Then:**
- The function returns without error.
- `InstanceState.status` equals `.ACTIVE` (matching `instance_projections.status`).
- `InstanceState.tokens` contains exactly one token with `node_id = "end"`, matching
  `instance_projections.current_nodes`.
- `InstanceState.variables` contains `"result": "approved"`, matching
  `instance_projections.variables`.
- `InstanceState.pending_events` is empty (cleared after replay).

**Layer:** integration
**Acceptance criterion mapped:** AC-1 (N-event replay produces InstanceState equal to the
persisted projection field-for-field: tokens, variables, status)

---

### TC-EE-11-02: Empty event log returns InstanceNotFound

**Given:**
- A UUID that has no rows in `events` and no rows in `events_archive`.

**When:**
- `reconstructInstance(allocator, pool, snapshot_store, unknown_id, false)` is called.

**Then:**
- `ReconstructionError.InstanceNotFound` is returned.
- No panic or undefined behaviour.

**Note:** EE-11 requirement edge case says "0 events → initial state", but the
implementation returns `InstanceNotFound` because 0 events means the instance was never
started (design §5). The test verifies the implemented behaviour.

**Layer:** integration
**Acceptance criterion mapped:** Edge case — 0 events; InstanceNotFound maps to HTTP 404
(handleReconstruct §7)

---

### TC-EE-11-03: EXECUTION_ERROR in event log sets reconstructed status to ERROR

**Given:**
- An ACTIVE process instance whose event log contains (in order):
  `instance_started` (start_node_id=`review_task`, initial_variables=`{}`),
  `EXECUTION_ERROR` (payload=`{"error_type":"NO_MATCHING_EDGE","affected_node":"gw1",
  "reason":"no matching edge","variable_state":"{}"}`).
- Additional events exist after the `EXECUTION_ERROR` row to confirm replay halts.

**When:**
- `reconstructInstance(allocator, pool, snapshot_store, instance_id, false)` is called.

**Then:**
- The function returns without error.
- `InstanceState.status` equals `.ERROR`.
- `InstanceState.error_detail` is non-null and contains the `EXECUTION_ERROR` payload JSON.
- The tokens and variables reflect the state immediately before the `EXECUTION_ERROR` (i.e.
  events after `EXECUTION_ERROR` were NOT applied — replay loop broke immediately).

**Layer:** integration
**Acceptance criterion mapped:** Edge case — EXECUTION_ERROR halts replay; reconstructed
status = ERROR (design §4 step 4)

---

### TC-EE-11-04: Reconstruction spanning events + events_archive produces identical result

**Given:**
- A process instance with 10 ordered events (sequence_numbers 1–10).
- Events with sequence_numbers 1–5 exist only in `events_archive`.
- Events with sequence_numbers 6–10 exist only in `events`.
- A control instance with all 10 events in `events` only.

**When:**
- `reconstructInstance` is called on both instances.

**Then:**
- Both calls return without error.
- The returned `InstanceState.status`, `tokens`, and `variables` are identical between
  the two instances.

**Layer:** integration
**Acceptance criterion mapped:** AC-5 (reconstruction spanning events + events_archive
produces identical results to events-only reconstruction)

---

### TC-EE-11-05: NFR-04 performance — 10,000 events complete in ≤ 5 seconds

**Given:**
- A process definition with a single HUMAN_TASK cycle: `start` → `task` → `end`.
- A process instance with exactly 10,000 events inserted directly via SQL (synthetic
  loop of alternating `instance_started` + repeated `task_completed` events, with each
  task_completed advancing a counter variable).
- Test environment has a real PostgreSQL database (BPM_TEST_DB_URL).

**When:**
- Wall-clock start time is recorded.
- `reconstructInstance(allocator, pool, snapshot_store, instance_id, false)` is called.
- Wall-clock end time is recorded.

**Then:**
- The function returns without error.
- Elapsed wall-clock time is ≤ 5,000 ms (5 seconds).
- `InstanceState.status` is a valid value (not undefined/garbage).

**Layer:** integration
**Acceptance criterion mapped:** AC-2 (NFR-04: reconstruction of up to 10,000 events
completes in ≤ 5 seconds)

### TC-EE-11-06: Write-back — reconstruction with write_back=true updates instance_projections

**Given:**
- An ACTIVE process instance with a valid event log (at least one `instance_started` +
  one `task_completed`).
- The `instance_projections` row exists but has deliberately stale values:
  `current_nodes = '[]'`, `variables = '{}'` (simulating a degraded read model).

**When:**
- `reconstructInstance(allocator, pool, snapshot_store, instance_id, true)` is called
  (write_back = true).

**Then:**
- The function returns without error.
- `instance_projections.status` matches the reconstructed status.
- `instance_projections.current_nodes` is updated to the correct token list.
- `instance_projections.variables` is updated to the correct variable map.
- `instance_projections.updated_at` is greater than its value before the call.

**Layer:** integration
**Acceptance criterion mapped:** AC-4 (write_back=true writes reconstructed state back to
the projection table to restore the read model)

---

### TC-EE-11-07: POST /instances/{id}/reconstruct — HTTP 200 on valid instance

**Given:**
- A running process instance with at least one event in its log.
- The caller has operator role permissions.

**When:**
- `handleReconstruct(store, allocator, instance_id_str)` is called with the valid UUID
  string, or equivalently `POST /instances/{id}/reconstruct` is issued.

**Then:**
- The handler returns HTTP 200.
- Response body is valid JSON with fields: `instance_id` (UUID string), `status` (string),
  `tokens` (JSON array), `variables` (JSON object).
- `status` matches the reconstructed instance status.

**Layer:** integration
**Acceptance criterion mapped:** AC-1 + HTTP endpoint contract (handleReconstruct §7
returns 200 with InstanceState JSON body)

---

### TC-EE-11-08: POST /instances/{id}/reconstruct — HTTP 404 on unknown instance

**Given:**
- A UUID that has no events in `events` or `events_archive`.

**When:**
- `handleReconstruct(store, allocator, unknown_id_str)` is called.

**Then:**
- The handler returns HTTP 404.
- Response body contains `"error_code": "INSTANCE_NOT_FOUND"`.

**Layer:** integration
**Acceptance criterion mapped:** Edge case — InstanceNotFound → HTTP 404
(handleReconstruct error map §7)

---

### TC-EE-11-09: Corrupt or absent projection — reconstruction succeeds from event log alone

**Given:**
- A process instance with a valid event log (INSTANCE_STARTED, TASK_COMPLETED).
- The `instance_projections` row for this instance is deleted (simulating a corrupt or
  absent read model).

**When:**
- `reconstructInstance(allocator, pool, snapshot_store, instance_id, false)` is called
  (write_back = false, so no UPDATE to instance_projections is attempted).

**Then:**
- The function returns without error.
- The returned `InstanceState` correctly reflects the state derived from the event log.
- No error is raised due to the missing projection row.

**Layer:** integration
**Acceptance criterion mapped:** AC-3 (reconstruction is possible even if the read-model
projection table is corrupt or absent)

## Unit Tests (no DB required)

### TC-EE-11-U01: ReconstructionError — error set completeness

**Given:** The `ReconstructionError` error set in `src/engine/reconstruction.zig`.

**When:** Each expected variant is assigned to a typed `ReconstructionError` variable.

**Then:** Compile succeeds, confirming all 6 variants exist: `InstanceNotFound`,
`LockContention`, `PoolExhausted`, `QueryFailed`, `ReplayFailed`, `OutOfMemory`.

**Layer:** unit
**Acceptance criterion mapped:** All error paths are typed and exhaustively handled by
callers (structural correctness of the public error API)

---

### TC-EE-11-U02: Uuid type alias — same underlying [16]u8 type as snapshot_mod.Uuid

**Given:** `reconstruction_mod.Uuid` exported from `src/engine/reconstruction.zig`.

**When:** A zeroed `[16]u8` value is assigned and its length is checked.

**Then:** Compile succeeds and `len == 16`, confirming `Uuid = [16]u8`.

**Layer:** unit
**Acceptance criterion mapped:** `reconstructInstance` parameter type matches the UUID
type used across the platform

---

### TC-EE-11-U03: reconstructInstance function — publicly accessible in the module

**Given:** The `reconstructInstance` function declared `pub` in `src/engine/reconstruction.zig`.

**When:** The function pointer is referenced at compile time.

**Then:** Compile succeeds, confirming the function is public and accessible via the
`bpm.reconstruction` module alias.

**Layer:** unit
**Acceptance criterion mapped:** API is reachable by callers (routes, test harness) without
needing internal imports
