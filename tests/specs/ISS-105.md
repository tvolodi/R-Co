# Test Spec: ISS-105 — Persist New Token Model ({token_id, node_id} + join_counters)

**Requirement:** ISS-105 — `instances.active_tokens` stores `[{token_id, node_id}]`; new `instances.join_counters JSONB NOT NULL DEFAULT '{}'`. Backfill converts existing `[node_id]` arrays to `[{token_id:gen, node_id}]`. Replay from events reproduces identical `active_tokens` + `join_counters`.

**Priority:** MUST
**Test layer:** integration

## Acceptance Criteria

| ID | Criterion | Covered by |
|---|---|---|
| AC-1 | active_tokens column stores `[{token_id, node_id, branch_id}]` shape | TC-ISS-105-01 |
| AC-2 | join_counters column exists with DEFAULT '{}' | TC-ISS-105-02 |
| AC-3 | Backfill converts old `[node_id]` arrays to `[{token_id, node_id}]` | TC-ISS-105-04 |
| AC-4 | Replay from events reproduces identical active_tokens + join_counters | TC-ISS-105-03 |

## Test Cases

### TC-ISS-105-01: new instance has [{token_id, node_id, branch_id}] active_tokens
**Given:** A new process instance is started via InstanceStore.create()
**When:** The instance_projections row is SELECTed
**Then:** active_tokens is a JSONB array where each element has `token_id` (UUID string), `node_id` (TEXT), and `branch_id` (TEXT) fields. No element is a bare string.
**Layer:** integration
**Acceptance criterion mapped:** AC-1 (active_tokens shape)

### TC-ISS-105-02: join_counters exists and defaults to {}
**Given:** A new process instance is started
**When:** The instance_projections row is SELECTed
**Then:** join_counters column is a JSONB object (not NULL, not array). For a simple linear process, join_counters equals '{}'.
**Layer:** integration
**Acceptance criterion mapped:** AC-2 (join_counters column)

### TC-ISS-105-03: replay reproduces identical active_tokens + join_counters (structural)
**Given:** An instance exists with tokens and has emitted events
**When:** The instance state is reconstructed by replaying events through transition()
**Then:** The reconstructed active_tokens matches structurally (same node_id and branch_id values in same order). join_counters matches byte-for-byte. token_id values may differ (random UUID v4 until ISS-206).
**Layer:** integration
**Acceptance criterion mapped:** AC-4 (replay round-trip)

### TC-ISS-105-04: backfill converts old-shape current_nodes row
**Given:** A row with current_nodes = '["node_A", "node_B"]' (old format) and active_tokens = '[]'
**When:** The backfill UPDATE from migration 088 is executed
**Then:** active_tokens is converted to `[{token_id, node_id, branch_id}]` format. Each element has a generated token_id (non-empty UUID string). Original current_nodes is unchanged.
**Layer:** integration
**Acceptance criterion mapped:** AC-3 (backfill)
