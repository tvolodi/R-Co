# Test Spec: ISS-105 — Persist New Token Model ({token_id, node_id} + join_counters)

**Requirement:** ISS-105 — `instances.active_tokens` stores `[{token_id, node_id}]`; new `instances.join_counters JSONB NOT NULL DEFAULT '{}'`. Backfill converts existing `[node_id]` arrays to `[{token_id:gen, node_id}]`.

**Priority:** MUST
**Test layer:** integration

## Acceptance Criteria

| ID | Criterion | Covered by |
|---|---|---|
| AC-1 | active_tokens column stores `[{token_id, node_id, branch_id}]` shape | TC-ISS-105-01, TC-ISS-105-03 |
| AC-2 | join_counters column exists with DEFAULT '{}' | TC-ISS-105-02 |
| AC-3 | Backfill UPDATE is safe and idempotent | TC-ISS-105-04 |
