## Pre-run Fix Applied

**Issue found:** `tests/integration/db_integration_test.zig` and
`tests/integration/event_store_integration_test.zig` used `///` (doc-comment)
syntax immediately before `test` blocks, which is a Zig compilation error
("documentation comments cannot be attached to tests").

**Fix:** Converted all `///` prefixes to `//` regular comments in both
integration files. The stubs themselves were unchanged. This is an authoring
error in the test stub generation, not a logic defect.
