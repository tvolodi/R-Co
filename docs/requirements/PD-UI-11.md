# PD-UI-11 — Edge creation `[MUST]`

> The user SHALL connect two nodes by dragging from a source handle to a target handle. Edges from EXCLUSIVE_GATEWAY nodes SHALL prompt for a CEL condition expression or a "default edge" toggle on creation.

**See:** PD-06 (CEL condition syntax and default edge rules), PD-UI-16 (CEL expression editor widget), PD-UI-13 (inline validation of edge constraints)
