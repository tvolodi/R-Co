# SH-06 — API connectivity banner `[SHOULD]`

> If `GET /health/ready` returns non-200, the shell SHALL display a non-blocking banner: "Platform is currently unavailable — some actions may fail." The banner auto-dismisses when health recovers.

**See:** API-12 (`GET /health/ready` endpoint), FNFR-05 (error resilience — UI never left in broken state), ADM-UI-09 (health dashboard for detailed status)
