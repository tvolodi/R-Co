# PD-UI-07 — Export / Import `[SHOULD]`

> Each definition SHALL have an Export button that downloads the self-contained JSON document (PD-09). An Import button on the list view SHALL accept a JSON file and call the import endpoint.

**See:** PD-09 (`GET /definitions/:id/export` and `POST /definitions/import`), PD-UI-01 (Import button lives on the list view)
