# SH-05 — Global error boundary `[MUST]`

> An unhandled runtime error in any view SHALL be caught and render a recoverable error panel with a "reload this view" action, without crashing the entire application.

**See:** FNFR-05 (API failure resilience — a related but distinct concern), SH-03 (navigation remains functional while a single view is in error)
