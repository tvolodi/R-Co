# IN-UI-09 — Active token visualisation `[SHOULD]`

> On the instance graph view (read-only canvas), nodes that currently hold an active execution token SHALL be visually highlighted (e.g. animated pulse ring). Completed nodes SHALL be styled differently from pending nodes.

**See:** EE-02 (execution tokens tracked in InstanceState), IN-UI-04 (instance detail provides the token positions from `GET /instances/:id`), PD-UI-15 (read-only canvas used here)
