# IN-UI-04 — Instance detail view `[MUST]`

> Clicking an instance SHALL navigate to a detail page showing: current status, definition snapshot info, active tokens (highlighted on a read-only graph), current variable map, and active tasks.

**See:** API-03 (`GET /instances/:id`), PD-08 (snapshot stored at instance start — used here for graph display), IN-UI-05 (History tab on this page), IN-UI-06 (Timeline tab on this page), IN-UI-09 (active token visualisation on the read-only graph)
