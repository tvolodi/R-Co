# ADM-UI-05 — Group management `[MUST]`

> A Groups sub-section SHALL list all groups with member counts. The admin SHALL be able to: create new groups, add or remove members from existing groups, and delete empty groups.

**See:** IDN-02 (group model), API-10 (`POST /groups`, `PATCH /groups/:id`, `DELETE /groups/:id` — delete only if no members), ADM-UI-03 (group membership also editable per-user)
