# PD-UI-17 — Canvas minimap & zoom `[SHOULD]`

> The canvas SHALL include a minimap for large graphs and zoom controls (fit-to-screen, zoom in/out).

**See:** PD-02 (graphs up to 500 nodes and 2,000 edges — minimap needed for navigation), PD-UI-09 (React Flow canvas provides built-in minimap and zoom controls), FNFR-02 (zoom interactions must produce feedback within 100 ms)
