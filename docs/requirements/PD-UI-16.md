# PD-UI-16 — CEL expression editor `[SHOULD]`

> Edge condition inputs on EXCLUSIVE_GATEWAY SHALL use a code editor field (Monaco or CodeMirror) with CEL syntax highlighting and basic bracket matching. Syntax errors from the server (PD-06) SHALL be surfaced inline below the field.

**See:** PD-06 (CEL validation at definition save time), PD-UI-11 (edge creation flow where this editor appears), EXT-04 (variable transformer expressions also use CEL)
