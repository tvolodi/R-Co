# PD-UI-18 — Auto-layout `[SHOULD]`

> A "Re-layout" button SHALL apply an automatic DAG layout algorithm (e.g. Dagre) to arrange nodes cleanly.

**See:** PD-UI-09 (React Flow canvas receiving the re-laid-out node positions), PD-UI-19 (auto-layout should be an undoable operation)
