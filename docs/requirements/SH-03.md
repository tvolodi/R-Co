# SH-03 — Role-aware navigation `[MUST]`

> The global sidebar/navbar SHALL display only the navigation items the current user's role set permits. Items for areas outside the user's permissions SHALL be hidden entirely, not greyed out.

**See:** IDN-03 (role permission matrix), SH-01 (role set decoded after login), Appendix A (navigation structure and per-role gating)
