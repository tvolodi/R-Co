# TK-UI-03 — Dynamic form rendering `[MUST]`

> If the task node defines a `form_schema` (JSON Schema), the task detail panel SHALL render a dynamic form with appropriate field types (text, number, boolean, date, select, etc.). Required fields are enforced client-side before submission.

**See:** PD-05 (`form_schema` optional attribute on HUMAN_TASK nodes), TK-UI-04 (form values become the output_variables on submit), TK-UI-10 (mobile form operability required)
