# TK-UI-02 — Task detail panel `[MUST]`

> Clicking a task SHALL open a side panel (or navigate to a detail page on mobile) showing: node name, instance context (definition name, instance ID, correlation key), current variables available to the task, and the form schema rendered as an interactive form.

**See:** API-04 (`GET /tasks/:id`), TK-UI-03 (form schema rendering), TK-UI-04 (complete action in this panel), FNFR-07 (mobile viewport — side panel becomes full page at 375 px)
