# TK-UI-10 — Mobile task completion `[MUST]`

> The task detail view and complete flow SHALL be fully operable on a 375 px viewport with no clipping or horizontal scrolling.

**See:** FNFR-07 (mobile-responsive constraint, 375 px), TK-UI-02 (task detail panel becomes full page on mobile), TK-UI-03 (form fields must reflow on mobile), TK-UI-04 (complete button accessible on mobile)
