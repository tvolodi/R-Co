# PD-UI-15 — Read-only mode `[MUST]`

> Definitions with status ACTIVE, DEPRECATED, or ARCHIVED SHALL open in read-only mode. The canvas is non-interactive; node/edge details are still viewable. A banner communicates the read-only state.

**See:** PD-04 (definition lifecycle — DRAFT is the only editable state), PD-UI-09 (canvas rendered non-interactively), IN-UI-09 (active token visualisation also uses read-only canvas)
