# SH-02 — Session persistence `[MUST]`

> The authenticated session SHALL persist across page reloads (stored in `httpOnly` cookie or in-memory with a silent re-auth flow). Expired or revoked tokens SHALL trigger an automatic redirect to the login screen with a session-expired message.

**See:** FNFR-06 (token storage security — no localStorage/sessionStorage), SH-01 (login screen shown on expiry redirect), API-08 (401 response triggers session expiry detection)
