# SH-04 — Active user indicator `[MUST]`

> The shell SHALL display the current user's `display_name` and roles in the header. A logout action SHALL clear the session and return to the login screen.

**See:** IDN-01 (`display_name` field on user record), SH-01 (login screen returned to after logout), SH-02 (session cleared on logout)
