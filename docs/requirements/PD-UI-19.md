# PD-UI-19 — Undo / redo `[SHOULD]`

> The canvas SHALL support undo/redo (Ctrl+Z / Ctrl+Y) for all canvas operations (add node, delete edge, move node, edit property).

**See:** PD-UI-14 (unsaved changes tracked — undo history also part of this), FNFR-03 (keyboard navigation must be fully supported)
