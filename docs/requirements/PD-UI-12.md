# PD-UI-12 — Node properties panel `[MUST]`

> Clicking a node SHALL open an inline properties panel where the user can set all required and optional attributes for that node type (e.g. `assignee_type`, `assignee_ref`, `form_schema`, `escalation_timer_duration` for HUMAN_TASK).

**See:** PD-05 (mandatory and optional attributes per node type), SCH-04 (`escalation_timer_duration` on HUMAN_TASK), PD-UI-13 (validation errors shown in panel)
