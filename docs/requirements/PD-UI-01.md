# PD-UI-01 — Definition list `[MUST]`

> The definitions view SHALL display a paginated, searchable table of all process definitions showing: name, latest version, status badge (DRAFT / ACTIVE / DEPRECATED / ARCHIVED), and creation date.

**See:** PD-07 (`GET /definitions` endpoint with pagination and filters), API-06 (cursor-based pagination), PD-UI-02 (status filter on this list), PD-UI-03 (version history expansion)
