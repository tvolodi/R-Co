# PD-UI-06 — Activate confirmation `[MUST]`

> Activating a definition that would deprecate an existing ACTIVE version SHALL show a confirmation dialog listing the version being deprecated before proceeding.

**See:** PD-03 (activating a new version deprecates the prior ACTIVE), API-02 (`POST /definitions/:id/activate`), PD-UI-05 (activate action on DRAFT row)
