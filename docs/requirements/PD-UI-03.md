# PD-UI-03 — Version history `[MUST]`

> Clicking a definition name SHALL expand an inline version history row showing all versions for that name, each with its status and a link to open that version.

**See:** PD-07 (`GET /definitions?name=` filter to fetch all versions), PD-03 (version management — only one ACTIVE per name), PD-UI-05 (lifecycle actions available per version)
