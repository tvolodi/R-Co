# IN-UI-08 — Auto-refresh `[SHOULD]`

> The instance board and detail pages SHALL poll for updates every 10 seconds (configurable). An indicator SHALL show the last-refreshed time and a manual refresh button.

**See:** FNFR-02 (visible feedback within 100 ms — last-refreshed indicator satisfies this for polling), IN-UI-01 (board refreshed), IN-UI-04 (detail page refreshed)
