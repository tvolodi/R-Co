# ADM-UI-06 — Token list `[MUST]`

> An API Tokens sub-section SHALL display a table with columns: associated user, roles granted, expiry date, created date, revocation status. Token values are NEVER displayed in the list.

**See:** IDN-04 (token model — bearer token identity, revocation), API-10 (`GET /tokens`), ADM-UI-07 (issue action), ADM-UI-08 (revoke action per row)
