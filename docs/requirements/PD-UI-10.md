# PD-UI-10 — Node palette `[MUST]`

> A sidebar palette SHALL list all supported node types: START, END, HUMAN_TASK, EXCLUSIVE_GATEWAY, PARALLEL_GATEWAY (and SERVICE_TASK, TIMER, SUB_PROCESS when supported). Nodes are added to the canvas by drag-and-drop or double-click.

**See:** PD-05 (node types and their attributes), PD-UI-09 (canvas receiving dropped nodes), PD-UI-12 (properties panel opened after adding a node)
