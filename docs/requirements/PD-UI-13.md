# PD-UI-13 — Inline validation feedback `[MUST]`

> The canvas SHALL run client-side graph validation (mirroring PD-02 rules) continuously and display inline error indicators on offending nodes/edges (e.g. a red border on an isolated node). A validation summary panel SHALL list all errors before save is allowed.

**See:** PD-02 (graph validation rules mirrored client-side), PD-05 (node attribute validation), PD-06 (edge condition validation), PD-UI-14 (save blocked until validation passes)
