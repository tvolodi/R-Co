## What could be improved

- **6 stale items in `handoffs/global_queue.json` were already closed on GitHub**
  but still listed as `PENDING` in the queue. This wasted a few minutes during
  Step 00 hand-off verification. The queue needs a stale-entry sweep — either
  automatically (compare queue IDs to GitHub state on each `queue:list`) or
  manually (delete the entries during a dedicated sweep workflow).
- **The TEST-RUNNER subagent failed once and required ORCH to write the report
  directly.** The subagent's time budget was too short for a run that involved
  three integration binaries plus the bench precheck. Either the budget
  should be raised for this class of test runs, or the bench precheck should
  move into a dedicated subagent so its timeout does not starve the
  test-integration phase.
- **Branch base drift surfaced late.** The branch base `0e4d24bf` was
  post-WF02-plc-batch-b, but the `handoffs/orchestrator.log` referenced
  earlier WF02 runs whose bookkeeping showed up as `M` in `git status`. The
  bookkeeping files are stale on disk but harmless; a `git clean -fd
  handoffs/` post-merge would tighten the local state.

## Key learnings

- **The BPM Platform must keep the pre-flight gate body unchanged.** The gate
  is a contract with downstream consumers; adding conditions inside the gate
  body (rather than around it) would change its semantics. The fix preserves
  the gate body byte-for-byte and adds behaviour via env injection + a
  post-condition assertion. This pattern should be the template for any future
  GBL-* bench pre-flight adjustment.
- **Bench is a separate channel from CI and must receive its own env
  injection.** `run_migrate.zig` reads `BPM_DB_URL` directly because the bench
  wrapper script does not propagate the full CI env. Any future bench
  integration must take this env-injection responsibility explicitly.
- **Integration tests need their own dedicated test target.** The fix added a
  dedicated `test-integration-iss0706` build target so the regression can run
  on its own schedule (parallel pool, serial chain, or ad-hoc) without
  dragging in unrelated binaries. Future GBL fixes should follow the same
  pattern.
