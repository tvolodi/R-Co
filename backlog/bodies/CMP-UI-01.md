> `design-tokens/r-co.tokens.json` SHALL be the only file in which a colour, type, spacing or radius value is authored, and `web/src/styles/tokens.css` SHALL be generated from it as `:root` custom properties. The generated key set SHALL equal the token set specified in `docs/guides/frontend_design_system.md` §2.1, §2.2, §3 and §4: `--color-neutral-0` through `--color-neutral-900`, `--color-brand-400` through `--color-brand-700`, the light, base and dark triplets of `--color-success`, `--color-warning`, `--color-error` and `--color-info`, `--surface-page`, `--surface-card`, `--surface-sidebar`, `--surface-overlay`, `--text-primary`, `--text-secondary`, `--text-disabled`, `--text-inverse`, `--border-default`, `--border-focus`, `--border-error`, `--interactive-primary`, `--interactive-primary-hover`, `--interactive-danger`, `--interactive-danger-hover`, `--font-sans`, `--font-mono`, `--text-xs` through `--text-3xl`, `--font-normal` through `--font-bold`, `--space-1` through `--space-16`, `--radius-sm`, `--radius-md`, `--radius-lg`, `--radius-full`, `--sidebar-width`, `--content-max-width` and `--panel-width`.

**Acceptance Criteria:**
- GIVEN the committed `web/src/styles/tokens.css`, WHEN the generator is run against `design-tokens/r-co.tokens.json` and the output is compared byte for byte, THEN the files are identical; drift fails `npm run build`. This is a pure static check with no HTTP.
- GIVEN the token key set parsed from `tokens.css`, WHEN it is compared against the key set enumerated above, THEN the two sets are equal, and a key present in one and absent from the other fails the parity check with the key name.
- GIVEN `--surface-card`, `--text-primary` and `--interactive-primary` in the generated file, WHEN each is resolved, THEN it resolves through a `var()` reference to a base palette token and holds no literal value of its own.
- GIVEN a Playwright E2E loads the Instance List against the real backend, WHEN `getComputedStyle(document.documentElement)` is read, THEN every key in the enumerated set resolves to a non-empty value.
- The generator is invoked by the `build` script, so a hand-edit of `tokens.css` without a matching edit to the JSON cannot reach `main`.
